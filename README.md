# OptiFit AI — אבטיפוס

מערכת חכמה להתאמת מסגרות משקפיים באמצעות ניתוח פנים.
פרויקט גמר, מכללת אשקלון.

## התקנה והרצה מהירה (מהאפס)

לאחר הורדת הפרויקט (clone / הורדת ZIP), מתיקיית השורש:

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
bash download_model.sh
.venv\Scripts\python server.py
```

ואז פותחים בדפדפן **http://localhost:8000**.
פירוט מלא של שתי דרכי ההרצה נמצא בהמשך, תחת "שתי דרכי הרצה".

## בדיקות (Unit Tests)

בדיקות היחידה כתובות ב-`unittest` מספריית התקן — לא צריך להתקין שום דבר. מריצים מתיקיית השורש:

```bash
.venv/Scripts/python.exe -m unittest discover -s tests -v
```

הבדיקות מכסות את שני רכיבי הליבה של הלוגיקה:
- **`test_face_shape_classifier.py`** — סיווג נכון של חמש צורות הפנים ממדדים סינתטיים, ותמיד מחזיר צורה חוקית.
- **`test_recommendation_engine.py`** — מיון לפי ציון, טווחי אחוזים תקינים (0–100), סינון לפי קטגוריה, וחישוב Size Match רק כשהוזנה מידה ידועה.

## שתי דרכי הרצה

### 1) חוויית Live Virtual Try-On הפרימיום (מומלץ)
ממשק דו-לשוני (עברית/אנגלית), עיצוב כהה, מצלמה חיה + מעקב פנים בזמן אמת + הדבקת מסגרות חיה:

```bash
.venv/Scripts/python.exe server.py
```

> הערה: משתמשים ב-`python` של סביבת ה-`.venv` כי פקודת `python` הגלובלית במחשב עשויה
> להיות קיצור של חנות Windows שאינו מריץ את המפרש.

ואז פותחים **http://localhost:8000** (הדפדפן יבקש הרשאת מצלמה). דורש אינטרנט לטעינת
ספריית MediaPipe וה-Font. אם אין מצלמה/הרשאה — אפשר **להעלות תמונה** במקום.
כל לוגיקת ה-AI (ניתוח פנים, צבעים, ניקוד, המלצות) רצה בשרת Python מתוך אותם מודולים קיימים.

#### מה יש בממשק הווב (`web/app.js`)
- **צילום או העלאת תמונה** — במסך המדידה בוחרים בין מצלמה חיה לבין העלאת תמונה קיימת.
- **מעקב פנים והנחת מסגרת** — 468 נקודות ציון (MediaPipe JS) מניחות את המסגרת על העיניים,
  עם התאמה מחדש אוטומטית גם אחרי מעבר בין עמודים.
- **כוונון ידני** — כפתור "כוונון": גרירה, הגדלה/הקטנה (כפתורים או גלגלת) וסיבוב של המסגרת;
  "Done" נועל את המיקום, "התאמה אוטומטית" חוזר לזיהוי האוטומטי.
- **השוואת 3 המובילות** — שלוש המסגרות עם ההתאמה הגבוהה ביותר זו לצד זו על התמונה שלך.
- **צילום ושיתוף** — הורדת התוצאה כ-PNG או שיתוף ישיר (Web Share API בטלפון).
- **גלילה נעוצה** — התמונה נשארת מול העיניים בזמן גלילה ברשימת המסגרות.
- **שמירת מצב** — מועדפים ובחירת השפה נשמרים בין רענונים (`localStorage`).
- **נגישות** — ניווט מקלדת מלא (Tab/Enter/Space), תוויות ARIA, טבעת פוקוס, קישור דילוג לתוכן,
  וכיבוד `prefers-reduced-motion`.

## הדמיה ריאליסטית מבוססת AI (אופציונלי, בתשלום)

בממשק ה-Streamlit, בנוסף להדבקה הגיאומטרית המהירה, אפשר לייצר **הדמיה ריאליסטית**
של המסגרת הנבחרת על הפנים בעזרת מנוע יצירת התמונות של OpenAI (`gpt-image-1` —
אותו מנוע שמאחורי ChatGPT). לאחר ניתוח הפנים ובחירת מסגרת, לוחצים על הכפתור
**"✨ הדמיה ריאליסטית (AI)"** מתחת לתמונה המרכזית.

> ⚠️ השירות של OpenAI בתשלום לפי שימוש (כמה סנטים לכל הדמיה) ודורש מפתח API.
> ההדבקה הגיאומטרית הרגילה נשארת חינמית וברירת המחדל — אפשר להשתמש באפליקציה בלי מפתח כלל.

### הגדרת מפתח OpenAI

1. משיגים מפתח בכתובת <https://platform.openai.com/api-keys> (דורש חשבון עם יתרת חיוב).
2. מגדירים אותו באחת משתי דרכים:
   - **משתנה סביבה** (מומלץ) — ב-PowerShell:
     ```bash
     setx OPENAI_API_KEY "sk-..."
     ```
     ואז פותחים חלון טרמינל חדש ומריצים מחדש את האפליקציה.
   - **הזנה ישירה בממשק** — בסרגל הצד, תחת "✨ הדמיה ריאליסטית (AI)", מדביקים את המפתח
     בשדה. המפתח נשמר רק בזיכרון ה-session ולא נכתב לדיסק.

התוצאה נשמרת במטמון לפי מסגרת — לחיצה חוזרת על אותה מסגרת מציגה את ההדמיה מיד, בלי חיוב נוסף.

## מה כבר עובד

- ✅ זיהוי פנים (MediaPipe) + חילוץ מדדים + סיווג צורת פנים
- ✅ ניתוח צבעים עם ציון ביטחון (low/medium/high) — מזהה תאורה בעייתית
- ✅ מנוע המלצות v2: לכל מסגרת ציוני Shape/Color/Material/Thickness ו-Overall Match משוקלל
- ✅ Size Match אופציונלי — רק אם המשתמשת מזינה מידה של משקפיים נוחים לה
- ✅ הדמיה ויזואלית (Try-On) — מצלמה חיה או תמונה שהועלתה, עם הנחת מסגרת על הפנים
- ✅ כוונון ידני של המסגרת (גרירה / גודל / סיבוב) + נעילת המיקום
- ✅ השוואת 3 ההמלצות המובילות זו לצד זו על תמונת המשתמשת
- ✅ צילום ושיתוף התוצאה, שמירת מועדפים ושפה בין רענונים
- ✅ נגישות: ניווט מקלדת, ARIA, פוקוס נראה, ו-`prefers-reduced-motion`
- ✅ הדמיה ריאליסטית מבוססת AI (OpenAI gpt-image-1) — בממשק Streamlit, אופציונלי בתשלום
- ✅ ממשק כהה בהשראת מוקאאפ "Advanced AI Eyewear Fitting" (רקע כהה + דגשי תכלת)
